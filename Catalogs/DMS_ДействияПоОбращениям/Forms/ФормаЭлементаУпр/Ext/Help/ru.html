Описание дополнительных полей для шаблонов оповещения:

&Фамилия - Фамилия клиента

&Имя - Имя клиента

&Отчество - Отчество клиента

&НомерОбращения - номер обращения клиента

&ДатаОбращения - дата обращения

&ДатаОкончания - крайняя дата выполнения действия

&ДатаПланируемая - планируемая дата выполнения

&Исполнитель - Исполнитель назначенный на выполнение действия
