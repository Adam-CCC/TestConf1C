Пустой запрос заполнит реквизиты по метаданным если это не виртуальная таблица.

Таблица может быть описана с помощью запроса (Виртуальная).
Для возможности выгружать виртуальную таблицу в составе Объекта
необходимо соблюдать условие именования.
Пример:
Реальная таблица: Имя=Справочник.Контрагенты
Дополнительно необходимо выгрузить контактные данные из РегистрСведений.КонтактнаяИнформация
Виртуальная таблица Имя=Справочник.Контрагенты.ХХХ
где ХХХ произвольное имя, например Справочник.Контрагенты.КонтактнаяИнформация

Виртуальные таблицы соединяются по ссылке с предопределенным параметром "&Ссылка"
Параметр ссылка будет передан при выгрузке ссылки (в нашем случае Контрагент)

Пример:

текст запроса виртуальной таблицы
Выбрать * Из РегистрСведений.КонтактнаяИнформация ГДЕ Объект=&Ссылка
