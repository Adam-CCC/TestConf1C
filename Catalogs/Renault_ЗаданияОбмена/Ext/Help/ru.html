Фильтры

 

Для версии TDAF V2 существует 2 типа фильтров :

Фильтрация по количеству 

 

Обмен файлами может быть ограничен по количеству полученных/отправленных файлов.

Фильрация по названию файла

 

Файлы Renault.net имеют особенную структуру названия, состоящую из 5 полей. На каждое поле названия файла можно применить фильтр.

5 полей названия файла:

- ID дилера

- Класс приложения

- Имя приложения

- Номер аккаунта

- порядковый номер в последовательности файлов

Установка фильтра

 

Настройки фильтра содержаться в файлах с разрешением .props.

Каждый фильтр характеризуется ключевым словом и соответствующим ему значением.

В таблице ниже приведены связи между ключевыми словами фильтров и значениями, которые может принимать поле названия файла:

 

Фильтр

Ключевое слово

Значения

Направление потока, к которому применяется фильтр

MODE

‘UP’ or ‘DOWN’

Идентификатор дилера (BIR)

AFF_ID

Num <= 8 chars

Класс приложения

DCS_APP_CLASS

Alpha <= 3 chars

Наименование приложения

DCS_APP_APPLI

Alpha <= 3 chars

Application account

DCS_APP_COMPTE

Num <= 8 chars

Sequence number

DCS_NO_LOT

Num <= 4 chars

 

Если пара ключевое слово-значение не указана в файле *.props,  соответствующее поле не будет удалено.

 

Примеры :

 

Если значения:

MODE=DOWN

DCS_APP_CLASS=PAR

указаны в файле *.props, то TDFA скачает только файлы класса PAR.

 

DCS_APP_APPLI=CA

DCS_NO_LOT=99

В этом случае TDFA загружает и скачивает все файлы, в названии которых содержатся символы ‘CA’, и порядковый номер  содержит цифры ‘99’.
