Инструкция по использованию обработки "Остатки авто на складе и в заказах поставщикам".

     
  Обработка расположена в пунктах меню "Отчеты / Автосалон".
    
При её открытии происходит первоначальное заполнение таблицы автомобилей, которые есть на складе и в заказах поставщикам. 

Для актуализации информации, необходимо вновь нажать кнопку "Заполнить".

        
               Часть кнопок управления расположены над таблицей. Поясним их назначение и использование:

  Если отметить щелчком мыши любую ячейку в таблице, то при помощи первой кнопки можно включить отбор по текущему значению.

При помощи второй кнопки откроется форма настроек, в которой можно устанавливать любые, сколь угодно сложные, отборы по текущей таблице автомобилей.
  
При этом, часто используемые отборы можно сохранять при помощи кнопки "Отборы", а затем - восстанавливать.

При помощи третьей кнопки можно отключить все установленные отборы.

Четвёртая и пятая кнопка позволяют сортировать по возрастанию и убыванию значений в текущей колонке, которую необходимо отметить.

Шестая кнопка позволяет осуществить настройку списка автомобилей, спрятав лишние колонки.

Седьмая кнопка позволяет вывести текущую таблицу автомобилей в табличный или текстовый документ.

Все колонки можно перетаскивать. Если выйти из программы нормально, то есть через Файл / Выход, то при новом запуске последнее расположение колонок будет восстановлено.

         
              Дополнительно, под таблицей автомобилей, находятся несколько полей, позволяющих осуществлять отбор по спискам, имеющим соответствующие названия:
   
 То есть - по Дилерским центрам, по Владельцам, по Видам, по Марке, по Модели, по Году выпуска, по Типу кузова, по Типу топлива, по Типу КПП,

по Типу привода, по Цвету кузова, по Цвету салона, по Логистическому статусу.

После заполнения всех нужных списков, необходимо нажать расположенную в нижней части формы кнопку "Применить отборы"(Ctrl+O) .
