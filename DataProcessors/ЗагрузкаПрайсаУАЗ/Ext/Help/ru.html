Обработка предназначена для загрузки прайса УАЗ н автомобили.

 

                                           Обработка предназначена для загрузки прайс-листа на автомобили УАЗ из файла Excel.

Образец файла можно увидеть, нажав одноимённую кнопку на командной панели.

Важными в этом файле являются всего две колонки: номер 3 - с кодом модификации УАЗ и номер 7 - с максимальной ценой перепродажи.

Из колонки 3 выбирается Артикул, по которому в базе должен быть найден "Вариант комплектации".

Значение из колонки номер 7 будет подставлено в цену варианта комплектации автомобиля.

Остальные значения берутся из формы обработки.

 Вначале следует указать имя файла, затем - номер строки, с которой следует начать загрузку,

тип цен продажи и подразделение.

Если хоть один реквизит оставить незаполненным, то будет выдано сообщение об ошибке.

В результате обработки формируется документ  "Изменение цен на автомобили", который проводится.

Вновь созданный документ открывается на экране пользователя для контроля.
