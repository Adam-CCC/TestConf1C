Загрузка OPERACODV2

Назначение

Обработка предназначена для загрузки норм времени выполнения работ из файла нормировки работ системы OPERACODV2.

При ручной загрузке норм времени выполнения необходимо указать каталог расположения файлов с нормами. Затем в таблице отметить галочками те файлы, которые необходимо загрузить и нажать кнопку Выполнить.

При загрузке в системе автоматически обновляется регистр сведений Семейства автомобилей. Это служебный регистр сведений в котором хранится соответствие кода TAPV автомобиля его рангу нормировки работ.

После обработки у загружаемого файла расширение изменяется на .tx_
Для повторной загрузки таких файлов необходимо сменить расширение на .txt

Обработка поддерживает вызов со стороны сервера и регламентные процедуры.

Для вызова в регламентной процедуре необходимо вызвать экспортную процедуру ОбработатьФайлы.
В параметры процедуры необходимо передать таблицу значений со списком путей к файлам для обработки.
