
                  
                    Инструкция по использованию обработки "Анализ продаж б/у автомобилей".
                   
                  
     1.    Для использования обработки необходимо в шапке выбрать период заполнения, в котором будет осуществляться 
         поиск реализаций б/у автомобилей.
      
     2.   Далее вследует выбрать один из трёх вариантов заполнения:
            - по дилерскому центру,
            - по контрагенту,
            - по автомобилю.
           Если хотя бы один вариант заполнен, два остоальных становятся недоступны. Для получения 
         доступа к другому - следует очистить заполненный вариант.
      
     3.    Затем следует нажать кнопку "Заполнить".
         В резудьтате табличная часть обработки будет заполнена.
         Из табличной части можно попасть непосредственно в элемент справочника, либо в документ.
      
     4.    Если заполнение устраивает, необходимо нажать кнопку "Печать".
      
     5.    Из любой строки получившегося табличного документа можно по щелчку открыть 
        сам автомобиль и по кнопке "Перейти" просмотреть отчет "История автомобиля".
       
     6.    В форме обработки реализован механизм сохранения и восстановления настроек.
      
     7.    Кнопка "Отладка" позволяет просмотреть документы, на основании которых заполняется табличная часть обработки.
