Обработка "Импорт данных из audatex"

Назначение

Обработка "Импорт данных из audatex" предназначена для организации интерфейса к программному обеспечению Audatex (AudaPadWeb). Интерфейс к программным продуктам Аудатэкс может быть организован только через платформу AX.Net. Для работы данной обработки необходимо использование библиотеки Auda.dll. Данную библиотеку можно купить написав заявку на приобретение в службу техподдержки.

 

Первый запуск обработки следует производить с правами администратора операционной системы, т.к. при наличии библиотеки Auda.dll и при отсутствии информации о ней в реестре Windows будет произведена попытка регистрации данноой библиотеки. Также при первом запуске обработки следует заполнить параметры необходимые для работы с Audatex. Данные параметры  будут сохранены и использованы при последующих запусках данной обработки.

Параметры:
  • Пользователь AX.NET
  • Пароль пользователя AX.NET
  • Вид документа, в который необходимо загрузить данные
  • Табличную часть документа, в которую будут загружены детали
  • Табличную часть документа, в которую будут загружены работы

Если указан документ-приемник, то данные заносятся в указанный документ. В противном случае каждый раз создается новый документ. Если расчет (дело) было загружено ранее, то будет задан вопрос об обновлении информации, открытии документа, или отмены действия. Также доступна Кнопка проверки комбинации логина/пароля на платформе. При корректном вводе учетных данных и нажатии данной кнопки появляется сообщение “Комбинация логина/пароля успешно прошла проверку”.

Обработка обмена позволяет указать документ (заказ-наряд), в который будет производится загрузка дел из Audatex и настроить соответствие реквизитов документа данным о делах и расчетах Audatex. На странице указания параметров импорта вы можете выбрать к использованию уже существующую схему импорта или самостоятельно создать новую.

  • Вы можете открыть ранее сохранённую схему импорта.
  • Сохранить текущую схему импорта в файл xml
  • Установить готовую схему импорта для Альфа-Авто

Способ вызова

Вызывается из формы списка или формы документа заказ-наряд. Данную обработку также можно вызвать из интерфейса при помощи нажатия на кнопкуменю "Обработки - Импорт данных из Audatex".
