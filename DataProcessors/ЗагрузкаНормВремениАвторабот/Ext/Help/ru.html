Регламент пакетной выгрузки рабочих позиций в систему

 

Введение

 

При выполнении рабочего процесса возникает необходимость выгрузки большого количества рабочих позиций в систему 1С. 

Для этого используется специальное решение, позволяющее выгружать рабочие позиции пакетом.

 

Чтобы успешно провести такую операцию, важно соблюдать ряд требований и рекомендаций.

 

Основные требования

 

Формат файла

 

Файл должен быть представлен в формате Excel (.xls) и иметь следующий вид (см. рисунок 1):

 

Рисунок 1

 

Обязательно наличие следующих полей:

 

●        Артикул

●        Наименование

●        Норма часов

 

Эти поля являются обязательными для успешной выгрузки.

 

Порядок действий

 

Шаг 1. Подготовка файла

 

Перед началом выгрузки убедитесь, что файл соответствует указанным требованиям. 

Все строки и столбцы должны быть заполнены правильно.

 

Шаг 2. Загрузка файла в 1С

 

1.        Откройте программу 1С.

2.        Перейдите в раздел «Обработки».

3.        Выберите пункт «Загрузка норм времени авторабот».

 

Появится окно для выбора файла (см. рисунок 2).

 

Рисунок 2

 

 

Расшифровка окна:

 

 

 

 

 

 

●        Путь к файлу: выберите местоположение файла с автоработами.


 

●        Группа авторабот: укажите группу, куда будут выгружены данные. Важно: группа должна быть предварительно создана!

 

 

●        Марка: выберите марку автомобиля, для которой предназначены данные автоработы.

 

 

●        Прервать после: установите количество работ, которое необходимо выгрузить. Значение «0» означает полную выгрузку всех строк из файла.

 

 


Шаг 3. Запуск обработки

 

 

После заполнения всех полей нажмите кнопку «Загрузить». Начнется процесс загрузки и перерасчета позиций.

 

 

 

Проверка результата

 

По окончании операции система выдаст уведомление о завершении загрузки. Проверьте правильность выгрузки:

 

●        Убедитесь, что все позиции были загружены корректно.

●        Используйте полученные данные в дальнейшем для оформления заказов-нарядов.

 

 

 

Заключение

 

Следуя данному регламенту, вы сможете быстро и эффективно проводить пакетную выгрузку рабочих позиций 

в систему 1С, обеспечивая точность и надежность ваших операций.
