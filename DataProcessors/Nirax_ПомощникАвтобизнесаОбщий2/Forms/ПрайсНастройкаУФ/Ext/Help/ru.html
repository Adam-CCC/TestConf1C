Поиск продукции в прайс-листах производится после их загрузки в справочник прайс-листов.
Источником данных прайс-листов могут быть файлы на диске или вложения в электронные письма.
Возможны и другие источники - файлы на FTP - серверах, http - запросы и т.д.
Обрабатываются следующие типы файлов: xls, xlsx, csv (разделитель ;).   
Если возникла потребность в других источниках и/или типов данных - обратитесь к менеджеру.
Данные настройки содержат следующую информацию:

Для Файлов (FILE): 
  Файл - полное имя файла. 

Для EMAIL:
 - Получатель - Ваш электронный адрес на который получаете прайс-листы. При первом вводе будет отображена дополнительная форма на которой нужно ввести пароль и определить данные почтовых серверов (см. справку на этой форме). Подключение для получения писем возможно по протоколу: IMAP. Подключение происходит автоматически при выборе Получателя, при этом фон Получателя отображает протокол - зеленый.
 - Почтовый ящик - Куда вы помещаете полученные письма, обычно это Входящие (INBOX);
 - Отправитель - email отправителя;
 - Тема - может содержать фразу, которая всегда присутствует в письмах с прайсом, например: "Прайс-лист" - позволяет более быстро найти нужный прайс-лист;
 - Вложение - полностью аналогичен файл (шаблон) - шаблон имени файла во вложении.
  - Срок действия, час - срок в течении которого действует прайс-лист, обычно это 24 часа. Срок действия берется относительно даты отправки письма, для файлов - дата последнего изменения. Если Вы определили автоматическую загрузку прайс-листов, то по истечении этого времени будут производится опросы для получения почты (файлов) и загрузки нового прайс-листа;
 - Частота опроса, час - через какой промежуток времени будет производиться опросы поступления почты (файлов). Значение 0 - определяет, что автозагрузка производиться не будет.

Описание структуры данных в файле.
Для описания структуры данных в файле рекомендуется загрузить файл / вложение: кнопка Загрузить для настройки. Если это вложение - нужно проверить что письмо не прочитано. При этом первые 30 строк файла появятся в табличном документе.

Требуется заполнить значения реквизитов:
 - Номер листа - для csv файлов всегда 1, этот реквизит заполняйте до нажатия кнопки загрузить;
 - Начальная строка - строка, начиная с которой будут загружаться данные;
 - Номера колонок обязательны: Артикул, Производитель, Цена;
 - Код товара - рекомендуется, если поставщик в прайсе использует свои коды, используются для оформления заказа;
 - Если отсутствуют колонки "Кратность" и "Минимальная партия" - будут значения = 1;
 - Если отсутствует колонка наличие, то объемы будут не определены;
 - Если отсутствует колонка срок доставки - сроки доставки будут не определены.

После того, как сохраните настройки и закроете форму - можно осуществить загрузку прайс-листа вручную и его просмотр (из формы Настройки).
Загрузка из файла производится только вручную.
