Обработка "Обработка  для демонстрации работы с SMS сообщениями"

Назначение

Обработка предназначена для демонстрации работы с исходящими SMS через оборудование. В модуле формы обработки показаны основные методы работы с SMS.

Способ вызова

Вызывается из меню "путь к меню"

Дополнительная информация

Данная обработка служит примером работы с SMS. Обработка позваляет отправлять SMS через устройства класса "Коммуникатор". Все методы использованные в данной обработке универсальны для работы с этим классом в независимости от типа оборудования (SMS4B или GSM модем)
