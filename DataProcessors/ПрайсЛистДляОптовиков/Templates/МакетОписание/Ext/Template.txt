 
       						Инструкция по запуску обработки "Прайс-лист для оптовиков".
       
       Параметр "Остатки вычислить на конец дня" - на конец этой даты вычисляются свободные остатки по складам дилерских центров.
      
       Параметр "Процент наценки" - себестоимость самой дорогой партии будет увеличена на этот процент и именно эта цена войдет в прайс-лист.
       
       Табличная часть используется для установки отбора по производителям.
       
       Причем, в зависимости от одноименного переключателя, существуют два варианта: "Включая производителей " и "Исключая производителей".
       
       Это имеет смысл делать в том случае, когда мы хотим сделать разную наценку по производителям, либо отобрать некоторых из них, либо проставить разную наценку.
       
       Есть механизм заполнения основных, неосновных, некорректных и  всех производителей. 
       
       Проценты наценки по включенным производителям имеют наивысший приоритет. Их можно заполнить при помощи кнопки над табличной частью.
       
        Соответствующие флажки устанавливаются при редактировании справочника Производители.
       
       Вторая таблица позволяет установить разные наценки по дилерским центрам. Если таблица не заполнена или ДЦ в нее не входит,
       
       то проценты будут взяты из шапки.
       
       Третья таблица позволяет внести получателей прайса. Вначале выбираем тип; Контрагент, Сотрудник или Контактное лицо.
       
       Если у этого элемента справочника есть Адрес электронной почты(рабочий), то он перенесется в таблицу. Можно заполнить и вручную.
       
       В четвёртой вкладке можно перечислить типы исключаемых складов (эта таблица также обязательна для заполнения), в пятой - исключаемых организаций, 
       
       а в шестой - заполнить по подразделениям, выбирая родителя в шапке таблицы и нажимая кнопку "Заполнить".
       
       В седьмой вкладке можно выбрать склады, причем есть кнопки "Очистить" и "Заполнить по группе". Причем вносятся только отсутствующие склады из 
       
       любого уровня иерархии.
       
       Следует быть внимательным, т.к. можно набрать такой набор условий, которому не будет соответствеовть ни одна запчасть.
       
       Кнопка Отладка предназначена для программистов. В отчете реализовано сохранение и восстановление значений.
       
       Если не включить флажок об отсылке почты, то будет сформирован файл Excell и отчет, но письма рассылаться не будут.
       
       Следует иметь в виду, что если указаны проценты наценки и по ДЦ и по включаемому производителю, то последний будет переписывать первый,
       
       т.е. наценка по производителю имеет более высокий приоритет.
       
       Флажок "Только заполнение" приведет к тому, что будет заполнена седьмая вкладка для ручного редактирования. Письма при этом рассылаться не будут.
       
       После её изменеия можно нажать кнопку "Для Автоформулы" и на рабочем столе появится файл Excel, который должен открыться для редактирования.
       
       В имени файла будет фигурировать сегодняшняя дата.
