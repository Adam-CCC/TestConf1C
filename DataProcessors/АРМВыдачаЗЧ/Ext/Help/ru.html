Обработка "АРМ Сотрудник цеха"

Назначение

Обработка "АРМ Сотрудник цеха" позволяет автоматизировать рабочее место сотрудника цеха, выполняющего операции учета рабочего времени. Поддерживаются следующие функции:

  • Авторизация с помощью карточки пользователя со штрих-кодом или вводом кода с клавиатуры;
  • Подбор работ по заказ-нарядам сканированием штрих-кода документа или выбором из списка заказ-нарядов;
  • Регистрация рабочего времени исполнителя;

Относится к подсистеме: «Учет рабочего времени».

Способ вызова

Вызывается из меню "Сервис --> Обработки --> Рабочее место "Сотрудник цеха" (АРМ)"

Дополнительная информация

Кнопка "Начать работу" - начинает интервал с видом отметки времени "работа" по текущему заказ наряду.

Кнопка "Начать простой" - начинает интервал с видом отметки, времени выбранной в диалоге выбора.

Кнопка "Начать рабочий день" - начинает интервал с видом отметки времени "простой", расценивается как ожидание работы.

Кнопка "Конец рабочего дня" - начинает интервал с видом отметки времени "Нерабочее время", используется в конце рабочей смены для закрытия всех важных для учета интервалов.

При старте любого нового интервала закрываются все ранее открытые интервалы для авторизированного пользователя.
