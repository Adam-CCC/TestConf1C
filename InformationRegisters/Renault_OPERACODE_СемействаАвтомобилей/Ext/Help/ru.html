В регистре хранится информация о соответствии послепродажного кода семейства автомобиля (TAPV) и ранга нормировки работ по данным систем BVM и OPERACODE.

Код TAPV можно узнать в системе BVM по VIN-коду автомобиля.

Измерения
TAPV - в этом поле хранится послепродажный код семейства
Тип значения - строка(4) переменной длины


Ресурсы
Ранг - в этом поле хранится ранг по которому производится нормировка работ
Тип значения - Число(2,0)

Реквизиты
На гарантии - в этом поле хранится признак активной гарантии.
Тип значения - Булево.
