В регистре хранится информация о нормах времени на автоработы по данным системы OPERACODE.
Нормировка работ выполняется по рангу автомобиля.

Ранг назначается послепродажному семейству автомобиля (TAPV). Код TAPV можно узнать в системе BVM по VIN-коду автомобиля.

Измерения
Код по каталогу - в этом поле хранится номер автоработы по каталогу OPERACODE.
Тип значения - строка(5) переменной длины.

Ранг - в этом поле хранится ранг для которого эта авторабота применима.
Тип значения - Число(2,0).

Авторабота - в этом поле хранится ссылка на автоработу в системе
Тип значения - Ссылка на справочники Автоработы или Номенклатура (см. таблицу).

Управление Производственным Предприятием или Управление Торговлей Справочник.Номенклатура


Ресурсы
Нормочас - в этом поле хранится значение нормочаса для текущей работы и ранга.
Тип значения - число(2,1).


Реквизиты
Вид работ - в этом поле хранится информация к какому виду работ относится данная работа.
Тип значения - Перечисление OPERACODV2_ВидыРабот.

Возможные значения:
M - Слесарные работы
T - Кузовные работы
P - Малярные работы

СложностьРабот - в этом поле хранится уровень технической сложности работ.
Тип значения - Перечисление OPERACODV2_СложностьРабот.

Возможные значения:
T1 - Нормальная
T2 - Повышенная
T3 - Высокая. слесарные работы
T4 - Высокая. Кузовные работы

Вид нормировки - в этом поле хранится числовое значение флага возможности свободной трактовки  данной нормы дилером.
Тип значения - строка(1).

Возможные значения:
0 - Работа нормирована, изменения наименования и норм запрещено
1 - Работа нормирована, изменение наименования запрещено, нормы устанавливает дилер
3 - Код присвоен, изменение наименования и норм разрешено
5 - Код не присвоен, изменение наименования и норм разрешено
