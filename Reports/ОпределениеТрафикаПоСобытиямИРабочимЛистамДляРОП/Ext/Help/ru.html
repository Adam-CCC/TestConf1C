а модель - содержит, либо не содержит фрагменты "б/у", "Б/У" или "пробег", в зависимости от значения параметров "Только новые"или "Только с пробегом".

         Входящие звонки:

6. ПТЗСС (Заявки с сайта)

7.ПТКС (КлиентыСервиса)

8.ИсходящиеЗвонки (ИсходящиеЗвонки)

 

ФПК:

9. ВсегоФПК = ФПКЗ + ФПКВ + ФПКЗСС (Всего)

10. ФПКЗ (Звонки) 

11. ФПКВ (Визиты)

12. ФПКЗСС (Заявки с сайта)

14. ФПККС (Клиенты сервиса) 

 

15. ТестДрайвы (ТестДрайвы)

16. ЛВПВЗ (Личные визиты после входящих звонков)

18. SR = Выбор Когда ПТЗ + ПТВ + ПТЗСС = 0  Тогда 0 Иначе Контракты / (ПТЗ + ПТВ + ПТЗСС) * 100 Конец ()

19. РасторжениеКонтракта (РасторжениеКонтракта)

21. Выдачи (Выдачи)

 

 Коэффициенты обработки (%)

22. КОВЗ = Выбор Когда ПТЗ = 0 Тогда 0 Иначе ФПКЗ / ПТЗ * 100 Конец (Звонков)
