	     		
	     		Инструкция по использованию "Отчета по неликвидам 2017".
	     
		В рамках этого отчета неликвидом считается товар, который был на складе на начало периода, в течение периода 
	не продавался и есть на складе на конец периода.
	
	В связи с тем, что было осуществлено слияние трёх баз, этот отчет формируется и по старым данным, хранящимся в текстовых файлах 
	на сервере.
	
	Период отчета следует задать кнопкой. 
	При выборе начала периода раньше 1 марта 2017 будет подставлена 01.03.2017 , а
	при выборе конца периода позже 1 декабря 2017 будет подставлена 02.12.2017 .
	
					На форму выведено несколько реквизитов:

	1). Период отчета - обязателен для заполнения. Заполняется по кнопке. В зависимости от выбора пользователя, дата конца всегла преобразуется к началу нужного месяца, а дата начала - к 01.01.2017.
	2). Группа 'Наши фирмы' требуется для того, чтобы исключить внутренние перепродажи. Реквизит обязательно должен быть заполнен.
	3). Номенклатура. Группа или элемент. Если выбрана Группа - то отчет будет формироваться только
	    по товарам, которые входят в эту группу. Если выбран элемент номенклатуры, то отчет будет формироваться только по нему.
	4). Склад.  Группа или элемент. Если выбрана Группа - то отчет будет формироваться только
	    по товарам, которые находятся на складах этой группы. Если выбран конкретный Склад, то отчет будет формироваться только по нему.
	5). Для адресов - из списка выбирается "Основной склад схемы" Справочника 'Схемы иерархических складов'. 
	    При выбранном значении в отчет дополнительно будет выводиться адрес хранения товара.
	6). Спискок органищзаций. Заполняется автоматически при открытиии отчета. Если проставить отметки, то при формировании
		отчета будет включен фильтр по отмеченым организациям. Перавая же отметка очищает реквизит формы 'Склад'. И наоборот, при выборе 'Склада' из 
		п.3, список организаций становится недоступным и с записей снимаются все пометки.
		Есть кнопки - "Проставить все пометки","Инвертировать" и "Снять все пометки".
		Если есть пометки в списке организаций, то склад очищается и становится недоступным. И наоборот. Если выбран
		Склад, то все пометки в списке снимаютсяЮ а сам список становится недоступным.
		
		Есть фильтр по производителям.
 	 		
		При выборе группы подражделений, будут выбраны склады, подразделения которого входят в выбранную группу.

 	Вначале следует нажать кнопку "Заполнить 2016". Спустя некоторое время станет доступна кнопка "Сформировать", которую также следует нажать.
 	В результате, должна появиться таблица, в которой 
	заполнены колонки: Каталожный номер, Номенклатура, Количество (на конец периода отчета) и Номер по порядку.
  		
	В отчете работает расшифровка, т.е. щелкнув по строке, можно провалиться в номенклатуру для проверки.
