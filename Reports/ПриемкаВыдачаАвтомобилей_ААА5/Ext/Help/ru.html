Отчет "Приемка/выдача автомобилей автосервиса"

Назначение

Отчет служит для вывода на мониторе в клиентской зоне.

Формы

  • ФормаНастроек. Основная форма настроек формирования отчета.
  • ФормаОтчета. Форма для вывода отчета на экран

Реквизиты

  • Показвать приемку, Показываеть выдачу. Настройка выводимых данных.
  • Дата начала, Дата конца. Задают интервал в минутах, отсчитывая от текущего времени.
  • Период смены страниц. Задает количество секунд, которое будет показываться каждая страница. Данные отчета обновляются только после вывода всех страниц.
  • Строк на страницу. Задает количество строк выводящихся на экран. Если указанное количество больше умещающегося на странице, то часть данных будет не видна.
  • Размер шрифта. Размер шрифта для вывода отчета.
  • Растяжение. Регулирует растяжение макета по ширине. Используется для подстройки под ширину монитора.

Способ вызова

Вызывается как внешняя печатная форма.

Дополнительная информация

При формировании отчета происходит поэкранный показ данных отчета.

Отчет формируется только на текущую дату.

Через 10 секунд после открытия формы настроек происходит автозапуск, который отключается кнокой "Отменить автозапуск".
