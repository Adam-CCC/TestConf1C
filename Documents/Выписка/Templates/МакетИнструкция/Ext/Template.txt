						
						Инструкция по работе с подсистемой заполнения банковских выписаок по актам от Производителя с перечнем гарантийных заказ-нарядов.
						
		 Изначально, сумма по акту, оплаченная производителем автомобиля, разносится одной строкой.
		 Спустя некоторе время, возникает необходимость разнести её по заказ-нарядам, в соответствии с приложенным  актом.
		 Порядок работы следующий.
		 
		 Прежде всего, бухгалтеру должен быть известен подкаталог, в котором инженер по гарантии (или другой сотрудник) размещает акты в формате "xls".
		 
		 В начале этого файла, приблизительно в пятой строке, во второй колонке, должен находиться номер Акта.
		 Затем в нём должна идти таблица следующей структуры:
		 2 колонка - номер заказ-наряда, возможно, с вопросительными буквами вместо русских букв.
		 3 колонка - VIN автомобиля.
		 5 колонка - оплаченная сумма по заказ-наряду.
		 
		 Для того чтобы начать обработку, бухгалтер должен в той строке, которую он собирается разделить по заказ-нарядам, заполнить две обязательных колонки:
		 1. Назначение платежа, обязательно содержащее в своём составе номер акта.
		 2. Номер акта, который желательно скопировать через буфер обмена из назначения платежа или файла Excel.
		 
		 Если обработка запускается впервые, то будет задан вопрос о необходимости её выполнения.
		 После этого программа попросит указать имя подкаталога с файлами Excel.
		 Затем она начнёт в цикле перебирать файлы и, читая их, пытаться найти номер акта.
		 Если найдёт, то начнёт добавлять строки с включённым флажком "Заполнено автоматически".
		 При этом, в добавленные строки, в поле 'назначение платежа' будет выводиться информация о номере заказ-наряда, VIN автомобиля и сумме, оплаченной производителем.
		 Обработка попытается найти гарантийный Заказ-гаряд с VIN и прописать его в таблицу.
		 
		 Если обработка запускается не впервые, то вначале она удалит все строки с включенным флажком "Заполнено автоматически".
		 Бухгалтер может снять вручную эти флажки и тогда строки удаляться не будут. Это сделано на случай, если в выписке надо разнести более, чем один Акт.
		 В то же время, наличие флажков позволяет неоднократно производить загрузку, не дублируя строчки с заказ-нарядами.
		 Снятие флажков можно произвести и по всей выписке, выбрав пункт меню: "Заполнение" / "Снять флажки 'Заполнено автоматически'".
		 По окончании обработки следует обнулить сумму прихода в первоначальной строке и убедиться, что исходящий остаток по счёту не изменился.
		 После этого следует записать (провести) банковскую выписку.
		 
		 Обработку можно также запустить, выбрав пункт меню: "Заполнение" / "Заполнить по акту из файлов Excel"
