Инструкция по работе с документом “Корректировка партий”.

 

       Документ “Корректировка  партий” предназначен для внесения начальных остатков по

  Компенсациям за продажу новых автомобилей. 

  Расположен по пути “Обработки / Все операции /  Документы /  Корректировка партий”.

 

Следует ввести новый документ:

 

     Дату остатков в шапке ставим ту, начиная с которой, бонусы начнут формироваться при продаже автомобилей.

   Далее необходимо нажать клавишу “Заполнить” над табличной частью  “Бонусные баллы дилера”.

   единственную колонку с VIN тех автомобилей, по которым необходимо внести первоначальные суммы бонусов за продажу:
