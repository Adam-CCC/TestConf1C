Документ "Пакет работ"

Назначение

Документ "Пакет работ" предназначен для фиксации перечня работ, выполняемых по документам "Заказ-наряд". 

 

Относится к подсистеме: «Учет рабочего времени».

Параметры

Длина номера: 10.

Периодичность номера: Непериодический.

Тип номера: Строка.

Вводится на основании:  ввод на основании не предусмотрен.

Объекты, вводимые на основании: ввод на основании не предусмотрен.

Реквизиты

  • Пост. Реквизит является обязательным для заполнения. Ссылается на справочник «Цеха». Пост (рабочее место), на котором выполняются работы.
  • Статус. Реквизит является обязательным для заполнения. Состояние выполнения пакета работ (выполняется/пауза/завершено).
  • Вид перерыва. Реквизит является не обязательным для заполнения. Ссылается на справочник «Виды перерывов в работе». Отражает причину приостановки работ, имеет смысл для пакетов работ, находящихся в состоянии "Пауза".  
  • Комментарий. Тип значения: «Строка». Произвольный комментарий к документу.
  • Подразделение. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделение компании, в котором был выписан документ.
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник «Организации». Идентификатор юридического лица, от которого выписан документ.
  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, породивший документ.
  • Операция. Реквизит является обязательным для заполнения. Ссылается на справочник «Хоз. операции». Выполняемая документом операция.

Табличная часть «Работы»

  • Заказ-Наряд. Реквизит является уникальным и обязательным для заполнения. Ссылается на документ «Заказ-наряд». Заказ-наряд, содержащий данную автоработу.
  • Идентификатор строки Заказ-наряда. Реквизит является уникальным и обязательным для заполнения. Тип: Строка(36). Содержит уникальный идентификатор (GUID) строки заказ-наряда. Введен для однозначной идентификации авторабот заказ-нарядов.
  • Работа. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Автоработы». Выполняемая авторабота.
  • Количество
    • . Реквизит является обязательным для заполнения. Тип значения: «Число». Количество единиц измерения авторабот.
  • Коэффициент. Реквизит является обязательным для заполнения. Тип значения: «Число». Норма времени выполнения автоработы.

Табличная часть «Сотрудники»

  • Сотрудник. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Сотрудники». Сотрудник, выполняющий работы. Для включение в пакеты работ могут использоваться только сотрудники с установленным флажком "Исполнитель".

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма документа. Используется для заполнения обязательных реквизитов.

Печатные формы

Возможность печати документа "Пакет работ" не предусмотрена.
