Документ "Списание ПТС (DMS)"

Назначение

Документ "Списание ПТС (DMS)" предназначен для ввода поступления ПТС на склад.

При проведении документ формирует хозяйственную операцию:

  • Остатки ПТС (DMS). Хозяйственная операция отражает списание ПТС.

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, породивший документ.
  • Склад компании. Склад компании, с которого списываются ПТС. Ссылается на справочник «Склады компании». 
  • Комментарий. Произвольный комментарий к документу.

Табличная часть «ПТС»

  • ПТС. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Подтверждающие документы». ПТС, для которого вводится списание.
  • Автомобиль. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Автомобили». Автомобиль, для которого вводится списание.
  • Ответственный. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Сотрудники». Ответственное за ПТС лицо.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма документа. Используется для заполнения обязательных реквизитов.

    Способ вызова

    Вызывается из меню "Продажи --> Журналы --> Движение ПТС".
