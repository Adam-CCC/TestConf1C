следует в строке с кредитной программой изменить статус  на “Одобрен”:

После этого следует заполнить суммы страхования и сделать отметки об оплате наличными (при необходимости). 

В результате будут будет рассчитано комиссионное вознаграждение и за программы страхования. А также изменится статус на Одобрен:

 

После этого следует заполнить< Дату первоначального взноса, и в одной из строк выбрать “Кредит выдан”:

 После этого надо нажать кнопку “Провести” или “Ок” (провести и закрыть). При проведении, результат 

расчета комиссионных вознаграждений, в случае наличия страховых продуктов, будет перенесён в проводки документа.

Если появляющиеся сообщения об изменении Рабочего листа не нужны – не следует заполнять флаг, показанный на картинке и наоборот:

 

Для продажи страховок можно ввести на основании текущего документа – Реализацию товаров.

 

Для этого необходимо, чтобы в таблице Страховых продуктов были заполнены колонки 

Подразделение Агента, Страховая компания и проставлена хотя бы одна отметка Формировать реализацию. 

Если строк с совпадающими Страховыми компаниями и Подразделениями Агента несколько, то отметить надо их все. 

Тогда эти страховые продукты попадут в один документ Реализации. 

Затем следует нажать кнопки “Записать” (ОБЯЗАТЕЛЬНО!)  и “ Ввод на основании”. И выбрать Реализация товаров.

Появившийся новый документ “Акт об оказании услуг” следует записать.

Аналогичные действия следует проделать для всех строк таблицы “Страховые продукты”.

 

После получения денег от клиента кассир сможет провести её.

 

            Общие принципы работы с РЛ КСО.

1. В АРМ “Ресепшн”  нужно добавить предмет обращения "Кредит, страхование". Это нужно для создания 

рабочих листов в том случае, когда клиент звонит или приходит целенаправленно в КСО,  минуя продавца Отдела продаж.

2. На основании РЛ отдела продаж нужно автоматически создавать РЛ КСО на сотрудника КСО,

 находящегося на работе в этом подразделении.

3. Если сотрудника КСО нет сегодня на работе, нужно сделать механизм разбора РЛ КСО без сотрудника, 

теми сотрудниками, которые работают в соседнем отделе продаж.

4. Сотрудник КСО должен определить форму оплаты (кредит или наличные)

5. Сотрудник КСО должен сделать предварительный расчет кредита и страховок. Для этого он:

- во вкладке "предварительный расчет" в РЛ должен выбрать контрагента из справочника или создать нового.

- внести сумму продажи а/м, первоначальный взнос, % ставку по кредиту, стоимость страховок и их наименование.

- нажать на кнопку "рассчитать",  которая вызовет кредитный калькулятор и произведет расчет.

6. Сотрудник КСО должен создать заявку на кредит и загрузить в эту заявку все необходимые документы.

7. Сотрудник КСО должен нажать кнопку отправить кнопку "отправить заявку", которая отправит все необходимые 

сведения в Фаст или в Екредит. После получения одобрения сотрудник КСО должен в 1С поставить 

отметку об одобрении в конкретном банке (банках).

8. После заполнения информации во вкладке сделка в РЛ отдела продаж вся информация об автомобиле и

 условиях приобретения должна попасть в РЛ КСО.

9. После выбора банка кредитора сотрудник КСО должен заполнить все сведения о банке кредиторе, выбранных страховках, 

их сумме и форме их оплаты в своем РЛ. Эта информация должна попасть в РЛ отдел продаж в соответствующую

 вкладку и отобразится в печатной форме чека менеджера.

10. Сотрудник КСО, при покупке  автомобиля  за наличные, должен выбрать наименование страховок и внести их предварительную 

стоимость для ознакомления клиента с ними.

11. Если клиента устроила стоимость, то сотрудник нажимает кнопку оформить продажу страховок, которая

 создаст реализацию в программе. 

Провести реализацию сможет только кассир после получения денежных средств от клиента.

12. Информация о проданных страховках при покупке а/м за наличные также должна передаться в РЛ 

отдела продаж и отобразится в печатной форме чека менеджера.

Назначение

Используется для фиксирования параметров кредита для потенциального покупателя автомобиля.

Параметры

Длина номера: 10.

Периодичность номера: Непериодический.

Тип номера: Строка.

Вводится на основании: «Событие», «Рабочий лист».

Объекты, вводимые на основании: «Событие».

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справлчник "Пользователи". Автор документа - пользователь, породивший документ.
  • Банк. Реквизит является обязательным для заполнения. Ссылается на справочник "Банки". Банк, через который оформляется кредит. 
  • Валюта заявленного дохода. Реквизит является обязательным для заполнения. Ссылается на справочник "Валюты". Валюта заявленного дохода.
  • Валюта документа. Реквизит является обязательным для заполнения. Ссылается на справочник "Валюты". Валюта документа.
  • Вид оплаты. Ссылается на перечисление "Виды оплаты". Вид оплаты документа.
  • Дата отправки анкеты. Тип значения: Дата.  Дата отправления анкеты клиента в банк.
  • Дата получения анкеты банком. Тип значения: Дата. Дата получения анкеты клиента банком.
  • Дата принятия решения. Тип значения: Дата. Дата принятия решения о кредитовании.
  • Дата сделки. Тип значения: Дата. Дата сделки.
  • Документ основание. Документ, на основании которого был введен рабочий лист кредитного отдела.
  • Заявленный доход. Реквизит является обязательным для заполнения. Тип значения: Число. Заявленный доход клиента.
  • Клиент. Ссылается на справочник "Контрагенты". Клиент.
  • Комментарий. Тип значения: Строка. Произвольный комментарий к документу.
  • Контактный телефон клиента. Реквизит является обязательным для заполнения. Телефон клиента, по которому он обратился в автосалон. Может быть выбран из списка, отредактирован или введен новый. Редактируется в диалоге. Для нового номера по умолчанию подставляется вид контактной информации "мобильный телефон". Если телефон с данным видом контактной информации уже задан в регистре для данного клиента, то задается вопрос о замене телефона либо выборе другого вида контактной информации для записи.
  • Кредитная программа. Ссылается на справочник "Кредитные программы". Кредитная программа.
  • Курс валюты. Тип значения: Число. Курс валюты управленческого учета документа.
  • Курс документа. Тип значения: Число. Курс валюты документа.
  • Менеджер. Реквизит является обязательным для заполнения. Ссылается на справочник "Сотрудники". Менеджер кредитного отдела.
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник "Организации". Идентификатор юридического лица, от которого выписан документ.
  • Первоначальный взнос. Реквизит является обязательным для заполнения. Тип значения: Число. Первоначальный взнос.
  • Подразделение компании. Реквизит является обязательным для заполнения. Ссылается на справочник "Подразделения компании". Подразделение компании, в котором был выписан документ.
  • Причина отказа. Ссылается на справочник "Возражения и причины отказов".. Причина отказа клиенту.
  • Проект. Ссылается на справочник "Проекты". Проект документа.
  • Процентная ставка. Реквизит является обязательным для заполнения. Тип значения: Число. Процентная ставка кредита.
  • Срок кредита. Реквизит является обязательным для заполнения. Тип значения: Число. Срок кредита.
  • Статус. Реквизит является обязательным для заполнения. Ссылается на справочник "Статусы рабочего листа". Статус рабочего листа кредитного отедла.
  • Стоимость автомобиля. Реквизит является обязательным для заполнения. Тип значения: Число. Стоимость автомобиля.
  • Сумма кредита. Реквизит является обязательным для заполнения. Тип значения: Число. Сумма кредита.
  • Требование к подтверждению дохода. Реквизит является обязательным для заполнения. Ссылается на перечисление "Требования к подтверждению дохода". Требование к подтверждению дохода.
  • Операция. Ссылается на справочник "Хоз. операции". Выполняемая документом операция.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма документа. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Документы --> Взаимоотношения с клиентами --> Рабочий лист кредитного отдела".
