Журнал документов "Движение ПТС (DMS)"

Назначение

Журнал документов предназначен для группировки и отображения документов, имеющих общую учетную сущность. Является удобным инструментом для отбора и просмотра документов. С его помощью возможен отбор по конкретным реквизитам и видам документов.  

Журнал "Движение ПТС (DMS)" содержит документы, отражающие учет движений ПТС в компании.

Список регистрируемых документов: «Ввод остатков ПТС (DMS)», «Поступление ПТС (DMS)», «Перемещение ПТС (DMS)», «Списание ПТС (DMS)».

Относится к подсистеме: «БСО».

Графы

  • Дата. Дата документа.
  • Номер. Номер документа учета ПТС. Нумерация для каждого типа документа своя. 
  • Тип документа. Тип документа учета ПТС.

Способ вызова

Вызывается из меню "Продажи --> Журналы--> Движение ПТС".
